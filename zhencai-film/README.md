# 甄采体制 · 中国三千年制度变迁史（史诗编年影片）

依据《甄采体制》专著目录架构（送审稿·第二版）第 7、8、9、10、11、12、13、15、16 章意象制作的 60 秒单文件 HTML 动画。

- 成品：`zhencai_epic_film.html`（双击用浏览器打开，点击画面开启配乐；`M` 静音，`F` 或双击全屏；播完自动循环）
- 规格：Canvas 2560×1090（2K，2.35:1），纯原生 JS，无外部资源；`requestAnimationFrame` 时间戳驱动，音画共用同一事件表（`EV`）
- 配乐：WebAudio 实时合成。上古周秦·陶埙，中古唐宋·古琴，近代古今·琵琶，当代追赶与智能时代·民乐交响（二胡、笛、古筝、琵琶、战鼓、编钟、锣）
- 调试：`?t=秒数` 冻结到指定时刻，便于截图检查
